# 🎬 VidCreator

Локальный веб-сервис для нарезки длинных видео на короткие клипы (Reels, TikTok, YouTube Shorts) по кастомным визуальным шаблонам.

---

## ✨ Возможности

### Студия и рекламные баннеры

- Новый интерфейс с пошаговой настройкой и предпросмотром; компоновка адаптирована с использованием 21st MCP ([Dashboard Sidebar, arunjdass](https://21st.dev/@arunjdass/components/dashboard-sidebar)).
- Разбивка по длительности, точному количеству клипов или ручным таймкодам. Остаток исходника сохраняется.
- Библиотека PNG/JPG/WebP, GIF и видеобаннеров MP4/WebM/MOV до 100 МБ. PNG сохраняют прозрачность. Рекламный звук не добавляется к исходному.
- Точное число показов **в каждой нарезке**. По умолчанию: два показа, первый с 26-й секунды, второй ближе к концу. Для статичных изображений длительность по умолчанию — 6 секунд; для видео и GIF — реальная длина каждого файла, один проход без повторов.
- По умолчанию **стоп-кадр и пауза звука** на время нашего рекламного баннера. В видео вставляется удержание кадра и тишина; затем всё исходное содержимое продолжается с того же места. Два показа по 6 секунд увеличивают итоговую длительность на 12 секунд. Можно выключить этот режим для обычного наложения поверх продолжающегося видео.
- Размер, положение, прозрачность, плавное появление и исчезновение. Один баннер на клип, чередование при каждом показе или общий баннер.
- Редактирование прямо в кадре: перетаскивание, изменение размера за четыре угла с сохранением пропорций, направляющие центра (Alt временно отключает привязку), кнопки масштаба и выравнивания. Стрелки двигают баннер, Shift увеличивает шаг; Alt + колесо меняет размер.
- Выбор области действия: все клипы или только текущий. Ctrl+Z отменяет изменение, Ctrl+Shift+Z возвращает его. Изменения перетаскивания сохраняются один раз после отпускания указателя; сервер не вызывается во время жеста.
- На дорожке рекламные показы можно перетаскивать, а правую границу статичного изображения — растягивать для изменения длительности конкретного показа. Длина видео/GIF привязана к файлу и не растягивается.
- Пять вариантов появления и ухода: плавное затухание, слайд снизу, слайд справа, масштабирование и без анимации. Вход и выход проходят внутри длительности файла; они не запускают ролик повторно.
- Для каждого клипа: своё число показов (0 отключает рекламу), свой баннер, точные локальные таймкоды. Маркеры показов открывают нужный момент предпросмотра.
- Если показы не помещаются или пересекаются, экспорт блокируется с объяснением. Число показов автоматически не уменьшается.
- Исходники, баннеры и история задач сохраняются на диске. Черновик настроек сохраняется в браузере. Прерванные перезапуском задачи отмечаются ошибкой, готовые файлы остаются доступны.
- Очередь обрабатывает одну задачу за раз. Частичные ошибки видны в интерфейсе, готовые клипы можно скачать даже при ошибках в других сегментах.

**Пример: 20 минут → 5 клипов по 4 минуты:** загрузить видео → выбрать шаблон → «По количеству», 5 → включить рекламу, выбрать баннеры, указать 2 показа. Со стоп-кадром показы каждого клипа начинаются на 26-й и 237-й секундах **исходного содержимого**, то есть на 26-й и 243-й секундах итогового видео; каждый файл длится 4:12. Без стоп-кадра показы начинаются на 26-й и 231-й секундах, длительность остаётся 4:00. В «Настроить этот клип» можно заменить баннер и расписание. Таймкоды настроек относятся к исходному содержимому; предпросмотр и дорожка показов отображают время готового файла.

Предпросмотр показывает композицию, цвет, рекламные анимации и стоп-кадры. GIF получает отдельный WebM для однократного воспроизведения в браузере; исходный GIF используется при экспорте. Проверяйте итоговый MP4 для точного отображения шрифта, кропа по числовым координатам, водяного знака и переходов шаблона. Реклама, уже вшитая в исходник, остаётся частью видео.

Сервис доступен на `http://localhost:3847` и слушает только локальный интерфейс. Для импорта YouTube используется `VIDKRAKEN_API_KEY` в окружении сервера или ключ, введённый в настройках импорта. Ключи не хранятся в исходниках. После изменения переменных окружения перезапустите сервер из нового терминала.

Проверки: `npm test` — расписание, нарезка, реальные FFmpeg-рендеры с проверкой пикселей до/во время/после рекламы, неподвижность кадра и тишина в рекламных паузах, продолжение исходного содержимого, однократное воспроизведение видео по длине файла, все варианты анимации, аудио, форматы и текст на русском со спецсимволами.

- **Импорт видео**:
  - Drag & Drop загрузка файлов с компьютера (MP4, MKV, AVI, MOV, WebM)
  - 🔴 **Прямая загрузка с YouTube** по ссылке в 1080p, 720p, 480p через VidKraken API
  - Автоматическое считывание метаданных (разрешение, FPS, длительность, кодеки) через `ffprobe`
- **Кастомные шаблоны**:
  - Настройка соотношения сторон: `9:16` (Reels/Shorts), `16:9` (YouTube), `1:1` (Instagram), `4:5`
  - Кроп и центрирование кадра под вертикальный формат
  - Цветокоррекция: яркость, контрастность, насыщенность
  - Текстовые наложения со стилями и таймингами
  - Водяные знаки (PNG) с выбором прозрачности и позиции
  - Плавные видео-переходы (Fade In / Fade Out) и аудиофейды
  - Встроенные пресеты: *TikTok & Reels*, *Shorts с хуком*, *Подкаст*, *Квадратный пост*
- **Умная нарезка**:
  - Автоматическая разбивка на сегменты по N секунд с настраиваемым перекрытием
  - Ручной ввод таймкодов
  - Интерактивный таймлайн
- **FFmpeg Рендеринг**:
  - Обработка видео и звука силами локального FFmpeg
  - Реалтайм-прогресс через Server-Sent Events (SSE)
  - Встроенный просмотр и скачивание готовых роликов

## 🛠️ Стек технологий

- **Backend**: Node.js, Express 5, child_process (FFmpeg & ffprobe)
- **Frontend**: Vanilla HTML5, CSS3 (кастомная тёмная дизайн-система), Vanilla JavaScript
- **API интеграция**: VidKraken API v2 для скачивания YouTube-видео

---

## 🚀 Быстрый старт

### Требования
1. [Node.js](https://nodejs.org/) v18+
2. [FFmpeg](https://ffmpeg.org/) (должен быть доступен в системном PATH)

### Установка и запуск

```bash
# 1. Клонирование репозитория
git clone https://github.com/inthethirtynine-beep/vidcreator.git
cd vidcreator

# 2. Установка зависимостей
npm install

# 3. Запуск сервера
node server.js
```

Сервер откроется по адресу: **http://localhost:3847**
