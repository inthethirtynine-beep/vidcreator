# 🎬 VidCreator

Локальный веб-сервис для нарезки длинных видео на короткие клипы (Reels, TikTok, YouTube Shorts) по кастомным визуальным шаблонам.

---

## ✨ Возможности

- **Импорт видео**:
  - Drag & Drop загрузка файлов с компьютера (MP4, MKV, AVI, MOV, WebM)
  - 🔴 **Прямая загрузка с YouTube** по ссылке в 1080p, 720p, 480p через VidKraken API
  - Автоматическое считывание метаданных (разрешение, FPS, длительность, кодеки) через `ffprobe`
- **Кастомные шаблоны**:
  - Настройка соотношения сторон: `9:16` (Reels/Shorts), `16:9` (YouTube), `1:1` (Instagram), `4:5`
  - Кроп и центрирование кадра под вертикальный формат
  - Цветокоррекция: яркость, контрастность, насыщенность
  - Текстовые наложения со стилями и таймингами
  - Водяные знаки (PNG) с выбором прозрачности и позиции
  - Плавные видео-переходы (Fade In / Fade Out) и аудиофейды
  - Встроенные пресеты: *TikTok & Reels*, *Shorts с хуком*, *Подкаст*, *Квадратный пост*
- **Умная нарезка**:
  - Автоматическая разбивка на сегменты по N секунд с настраиваемым перекрытием
  - Ручной ввод таймкодов
  - Интерактивный таймлайн
- **FFmpeg Рендеринг**:
  - Обработка видео и звука силами локального FFmpeg
  - Реалтайм-прогресс через Server-Sent Events (SSE)
  - Встроенный просмотр и скачивание готовых роликов

---

## 🛠️ Стек технологий

- **Backend**: Node.js, Express 5, child_process (FFmpeg & ffprobe)
- **Frontend**: Vanilla HTML5, CSS3 (кастомная тёмная дизайн-система), Vanilla JavaScript
- **API интеграция**: VidKraken API v2 для скачивания YouTube-видео

---

## 🚀 Быстрый старт

### Требования
1. [Node.js](https://nodejs.org/) v18+
2. [FFmpeg](https://ffmpeg.org/) (должен быть доступен в системном PATH)

### Установка и запуск

```bash
# 1. Клонирование репозитория
git clone https://github.com/akaruma/vidcreator.git
cd vidcreator

# 2. Установка зависимостей
npm install

# 3. Запуск сервера
node server.js
```

Сервер откроется по адресу: **http://localhost:3847**
