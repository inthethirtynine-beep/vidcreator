Вставь ссылку на видео или Shorts. Файл скачивается прямо на этот компьютер через yt-dlp, без ключей и сторонних сервисов, и сразу попадает в библиотеку.

Для загрузки нужен yt-dlp — бесплатный открытый загрузчик. Он скачается один раз из официального релиза на GitHub (около 18 МБ) и будет проверен по контрольной сумме.

Вход в YouTubeБез входа

Нужен, если YouTube просит подтвердить, что ты не бот (часто бывает с VPN), и для видео 18+. Данные входа остаются на этом компьютере и используются только для скачивания.

Вход через аккаунт Google — в карточке слева внизу. Войди один раз, дальше вход обновляется сам.

Другие способы

  1. Установи в Chrome или Edge расширение Get cookies.txt LOCALLY.
  2. Открой youtube.com, где ты вошёл в аккаунт.
  3. Нажми на расширение → Export и сохрани файл.
  4. Выбери этот файл здесь.

Кадрирование

Звук ускоряется без изменения тона. Длина клипов и время рекламы пересчитываются.

Углы и тень

Перетаскивай видео в предпросмотре, чтобы сдвинуть кадр, а колесом мыши меняй масштаб. Настройка запоминается для каждого видео и применяется ко всем клипам при экспорте.

Раскладка реакции

Обведи вебку стримера и область видео: вебка встанет сверху, видео — снизу. Рамки двигаются мышкой, размер меняется за углы.
